# AI-Powered Fraud Detection for M-Pesa Transactions

**Hackathon Project:** A machine learning web app that detects mobile money fraud in real-time.

## The Problem
SIM swap fraud in Kenya surged by 327% recently. Current systems are reactive. 

## The Solution
A Streamlit web app using a Random Forest model trained on the PaySim dataset to flag suspicious transactions before they clear.

## Tech Stack
Python, Scikit-Learn, Pandas, Streamlit.

## How to Run Locally
1. `pip install -r requirements.txt`
2. `streamlit run app.py`
